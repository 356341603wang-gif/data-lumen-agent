# R2V 维度分歧榜清晰化设计

## 目标

让第一次接触分歧分析的人在十秒内回答三个问题：

1. 哪些维度最需要对齐？
2. 每个维度有多少道题属于严重分歧？
3. 应该继续查看哪些具体题目？

## 当前问题

现有榜单把严重分歧率、平均分歧度、分歧发生率、混乱度和累计答案构成并列展示。使用者需要先理解四个指标才能形成结论；右侧累计答案数又与“有效题目单元”使用不同统计口径，容易被误认为两者应该相加对应。

## 设计方案

采用“行动型榜单”，保留现有 Data Atelier 视觉语言，改变信息层级而不改变分析口径。

### 页面摘要

榜单顶部增加结论卡，直接显示：

- 建议优先讨论的维度数量；
- 当前最值得对齐的维度名称；
- 严重分歧的判定口径：一道题中最高选项占比不超过 60%。

### 榜单行

每个维度默认只强调：

- 行动等级：优先对齐、建议关注或相对稳定；
- 严重分歧题数，例如“38 / 50 题”；
- 一句根据真实统计生成的诊断；
- 严重分歧题数占比进度条；
- 全部标注答案构成，使用百分比而非仅显示累计数量。

分歧发生率、平均分歧度和混乱度放入可展开的“详细指标”，不再与主结论争夺视觉优先级。

### 行动等级

- 优先对齐：严重分歧率大于或等于 50%；
- 建议关注：严重分歧率大于 0%，但低于 50%；
- 相对稳定：没有严重分歧。

这些等级只用于排序和排查，不替代标注能力结论。

### 相关题目

每行提供“查看相关题目”按钮。点击后进入单题分歧榜，并只显示该维度相关的严重分歧题；如果没有严重分歧，则显示该维度所有发生分歧的题。

## 数据口径

不修改现有指标计算：

- 有效题目单元：同一题、同一对象或 REF、同一维度，且至少有两份有效答案；
- 分歧发生：有效题目单元中出现两个及以上答案；
- 严重分歧：最高选项占比不超过 60%；
- 平均分歧度：每个题目单元中未选择多数答案的平均比例；
- 混乱度：用于区分两派争议与多种答案同时出现。

答案构成继续基于全部有效标注答案聚合，但界面明确标注统计口径并显示百分比。

## 响应式与可访问性

- 桌面端使用结论、题数进度和答案构成的横向证据链；
- 窄屏改为纵向卡片，保证主结论先出现；
- 展开详情使用原生 `details`；
- 按钮、进度条和答案分布提供可读标签；
- 不以颜色作为唯一的行动等级提示。

## 验证

- 单元测试覆盖行动等级、诊断文案和题目筛选；
- UI 源码测试确认默认层级和展开详情；
- 真实示例检查维度榜可读性以及单题下钻；
- 完整执行构建、静态站点构建、测试与代码检查。
